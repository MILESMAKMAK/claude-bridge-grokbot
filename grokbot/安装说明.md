# Claude防封桥接-grokbot版本 · 安装说明

适用环境：Grok Bot 的 box（Linux 容器，**没有 systemd**，出网**只有普通 HTTPS 443**，cloudflared 的 7844 端口被封）。
思路：服务只监听 `127.0.0.1`，由 `relay-agent.mjs` 主动用 wss(443) 连到你自己的 Cloudflare Worker + Durable Object，公网请求经 Worker 转回本机。

## 1. 依赖与构建
```bash
# Node.js >= 20、git、curl
git clone https://github.com/MILESMAKMAK/claude-bridge-grokbot ~/claude-bridge-grokbot
cd ~/claude-bridge-grokbot
npm ci && npm run build        # 以 package.json 中脚本为准
cd grokbot && npm install      # relay agent 依赖 ws
```

## 2. 部署 Worker 中继（在任何能登录 Cloudflare 的机器上）
```bash
cd grokbot/worker
cp wrangler.toml.example wrangler.toml   # 改 name = "<worker-name>"
npx wrangler login
npx wrangler deploy
openssl rand -hex 32                      # 生成中继密钥
npx wrangler secret put RELAY_SECRET      # 粘贴上面的密钥
```
固定地址为 `https://<worker-name>.<your-subdomain>.workers.dev`（Durable Object 免费额度可用）。

## 3. 配置并启动
```bash
cd ~/claude-bridge-grokbot/grokbot
cp bridge.env.example bridge.env && chmod 600 bridge.env
# 填写 BRIDGE_REPO / BRIDGE_DATA / RELAY_URL / RELAY_SECRET
./start.sh            # 首次启动；supervise.sh 每 5 秒自愈
./start.sh --restart  # 改配置后重启
```
看日志：`grokbot/bridge.log`、`relay.log`、`supervise.log`。本机检查：`curl http://127.0.0.1:8787/healthz`。
box 重启后需要重新执行一次 `./start.sh`（没有 systemd 开机自启）。

## 4. dimensio 模型 API Key
在网页界面 dimensio 的设置里填入 Anthropic / OpenAI / Gemini / DeepSeek / Kimi 等 API Key，
或写入 `$BRIDGE_DATA/dimensio/.env`（例如 `DEEPSEEK_API_KEY=...`）后 `./start.sh --restart`。

## 5. Claude Code 令牌
- 需要 **Claude Pro 或 Max** 订阅，免费账号不能用 Claude Code。
- 在 box 上 `claude login` 常被风控拦截，请在**自己的电脑**上运行 `claude setup-token`，浏览器授权后得到长期令牌，
  填入 `bridge.env` 的 `CLAUDE_CODE_OAUTH_TOKEN`，再 `./start.sh --restart`。
- 令牌、密钥只放在 `bridge.env`/`relay.secret`，已被 `.gitignore` 排除，切勿提交。
